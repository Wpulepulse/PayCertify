# 📜 Descripción de Certificaciones - PayCertify

## ¿Qué es una Certificación en PayCertify?

Una certificación es un documento digital verificable que acredita:
- ✅ Trabajo remoto realizado
- ✅ Cantidad de horas invertidas
- ✅ Monto pagado
- ✅ Plataforma de origen (Workana, freelancer, etc.)
- ✅ Verificación de autenticidad

## Elementos de una Certificación

### 1. **Encabezado**
```
Certificado de Trabajo Remoto
ID Certificado: CERT-2026-001-ABC123
Fecha de Emisión: 2026-08-24
Fecha de Vencimiento: 2027-08-24
```

### 2. **Datos del Trabajador**
```
Nombre: Juan Pérez
Username: juan_perez
Email: juan@email.com
GitHub: @juan_perez
Instagram: @juan_perez
```

### 3. **Datos del Proyecto**
```
Nombre del Proyecto: Desarrollo App Móvil
Descripción: Desarrollo de aplicación iOS con React Native
Plataforma Origen: Workana
URL Proyecto: https://workana.com/projects/...
```

### 4. **Detalles de Trabajo**
```
Horas Trabajadas: 120 horas
Fecha Inicio: 2026-07-01
Fecha Fin: 2026-08-24
Porcentaje Proyecto: 35%
Monto Total Proyecto: $5,000 USD
Monto Certificado: $1,750 USD (35%)
```

### 5. **Verificación de Autenticidad**
```
Hash SHA-256: a3b4c5d6e7f8g9h0i1j2k3l4m5n6o7p8
Firma Digital: [Clave pública de PayCertify]
Timestamp Blockchain: 2026-08-24T15:30:45Z
```

## Tipos de Certificaciones

### 🔵 Certificación Simple
- Una única tarea o proyecto
- Duración: 1-7 días
- Monto: Variable

### 🟢 Certificación Compuesta
- Múltiples tareas en un proyecto
- Duración: 8-90 días
- Monto: Suma de componentes

### 🟡 Certificación de Portfolio
- Agrupación de múltiples proyectos
- Duración: 90+ días
- Monto: Total acumulado

## Flujo de Generación de Certificación

```
1. Usuario finaliza proyecto en Workana
        ↓
2. Sistema detecta finalización via API
        ↓
3. IA verifica:
   - Horas trabajadas (GitHub commits, timestamps)
   - Calidad del trabajo (reviews, ratings)
   - Fraude potencial (análisis de patrones)
        ↓
4. Generación de Certificado Digital
        ↓
5. Firma con clave privada de PayCertify
        ↓
6. Almacenamiento inmutable (Blockchain opcional)
        ↓
7. Notificación al usuario
        ↓
8. Disponible para descargar/compartir
```
